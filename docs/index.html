MM Launcher

A free, light home screen for Android TV and Android boxes: all apps, favourites, quick access to hidden system settings (including Developer mode), HDMI/USB, a simple file manager, and Russian / Turkmen / English interface.

Install

  1. Copy the APK to a USB stick or download it on the box, then open it. Allow "install from unknown sources" if asked.
  2. Press Home on the remote, choose MM Launcher and Always.
  3. If the box does not ask, open the launcher, go to Launcher settings → Setup guide.

Google TV / Android TV with a protected home screen

Some devices do not let you replace the home screen from the screen. You then need a computer. Enable Developer options (About → press Build number 7 times), turn on USB or network debugging, then:

adb connect TV_IP_ADDRESS:5555
adb install mm-launcher.apk
adb shell cmd package set-home-activity com.mmlauncher.tv/.MainActivity

In the developer's Google TV test this command printed "success" but did NOT change the home screen. If it has no effect on your box, you can instead disable the original launcher (undo with pm enable): adb shell pm disable-user --user 0 com.google.android.tvlauncher (on Google TV the package is often com.google.android.apps.tv.launcherx). Results differ by device; test on one box first.

Google TV / Android TV с защищённым главным экраном

На некоторых устройствах заменить главный экран с самого экрана нельзя, нужен компьютер. Включите Режим разработчика (О устройстве → 7 раз нажать на Номер сборки), включите отладку по USB или сети, затем:

adb connect IP_АДРЕС_ТВ:5555
adb install mm-launcher.apk
adb shell cmd package set-home-activity com.mmlauncher.tv/.MainActivity

В тесте разработчика на Google TV эта команда писала «success», но главный экран НЕ менялся. Если у вас она не действует, можно отключить штатный лаунчер (вернуть: pm enable): adb shell pm disable-user --user 0 com.google.android.tvlauncher (на Google TV пакет часто com.google.android.apps.tv.launcherx). Результат зависит от устройства, сначала проверьте на одном боксе.
