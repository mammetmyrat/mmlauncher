MM Launcher: Privacy Policy

Short version: MM Launcher does not collect, store on a server or share any personal data. It has no accounts, no ads and no analytics.

What stays on your device

Your favourites, hidden apps, language, wallpaper and autostart choice are saved only on your device. The PIN/parental features are not part of this version.

Network use

The only network request is the optional update check. It is OFF until you turn it on in the setup wizard or in Launcher settings (the "Check now" button is also your explicit action). It downloads one small file, update.json, and, when a newer settings-compatibility file exists, settings_chains.json. The host serving these files (GitHub Pages) can see the IP address of your connection, as with any website. MM Launcher sends no identifiers; the request carries only the app name and version in the User-Agent.

A new APK is downloaded only after you press Install, over HTTPS, and is checked against a SHA-256 fingerprint before the system installer opens.

Permissions

  • Internet: update check only.
  • Request install packages: to open the installer after you confirm an update.
  • Read external storage: the built-in file manager and "set as wallpaper".
  • Kill background processes: the "free memory" button.
  • Request delete packages: the "Uninstall" menu item (the system asks you to confirm).
  • The launcher can see the list of installed apps in order to show them. This list never leaves the device.
