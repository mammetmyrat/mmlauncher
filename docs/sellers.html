MM Launcher: for box sellers

Before sale: checklist per box

  1. Install the APK (see below) and open MM Launcher once. The setup wizard starts.
  2. Choose the language and a wallpaper for the customer; answer "No" to auto-update if you prefer.
  3. Make it the home screen: press Home, choose MM Launcher, Always. Check that Home returns to it.
  4. Remove clutter: long-press (hold OK) on unwanted apps, then Hide. Add the customer's main apps to Favorites.
  5. Optional: Launcher settings → Autostart to open one app (for example the IPTV app) after power-on.
  6. Test: Wi-Fi button, About device, Developer mode button, HDMI/USB card if the box has them. Note any button that shows "can't open this screen" and tell the developer the box model and Android version: the settings-compatibility list can be updated without a new APK.

Install on many boxes at once

With ADB debugging enabled on the boxes (same network), from a computer:

scripts/install-on-boxes.sh mm-launcher.apk 192.168.1.50 192.168.1.51

Use --no-home to only install. Setting the home screen automatically works only on some versions; the script tells you which boxes need the manual "Always" step.

Installing as a system app

If you build or modify the firmware, the APK can be placed in /system/priv-app/ (or /system/app/) so it survives a factory reset. MM Launcher does not need privileged permissions. This path is not tested by the developer, so try it on one box first. Note that cleaning other apps' cache automatically needs system permissions the launcher does not have; the launcher opens the system Storage/Apps screens for that.

Перед продажей: чек-лист на каждый бокс

  1. Установите APK (ниже) и один раз откройте MM Launcher: запустится мастер настройки.
  2. Выберите язык и обои для покупателя; на вопрос об автообновлении ответьте «Нет», если так удобнее.
  3. Сделайте лаунчер главным экраном: Home → MM Launcher → Всегда. Проверьте, что Home возвращает на него.
  4. Уберите лишнее: удерживайте OK на ненужном приложении → Скрыть. Основные приложения покупателя добавьте в Избранное.
  5. По желанию: Настройки лаунчера → Автозапуск, чтобы после включения открывалось одно приложение (например IPTV).
  6. Проверьте: кнопку Wi-Fi, «О устройстве», «Режим разработчика», карточки HDMI/USB, если они есть. Если какая-то кнопка пишет «Не удалось открыть экран», сообщите разработчику модель бокса и версию Android: список совместимости настроек можно обновить без нового APK.

Установка на много боксов сразу

При включённой отладке ADB на боксах (одна сеть), с компьютера:

scripts/install-on-boxes.sh mm-launcher.apk 192.168.1.50 192.168.1.51

Параметр --no-home только устанавливает. Автоматически назначить главный экран получается не на всех версиях; скрипт сообщит, на каких боксах нужен ручной шаг «Всегда».

Установка как системного приложения

Если вы собираете или правите прошивку, APK можно положить в /system/priv-app/ (или /system/app/), чтобы он пережил сброс до заводских настроек. Особые привилегии MM Launcher не нужны. Разработчик этот путь не проверял, сначала попробуйте на одном боксе. Автоматическая очистка кэша чужих приложений требует системных прав, которых у лаунчера нет: он открывает системные экраны «Хранилище» и «Приложения».
